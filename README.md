# landing_page

Landing page responsiva da **Serra Viva Expedições**, criada para o exercício do módulo EBAC.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Gulp

## Automação com Gulp

1. Instale as dependências:

```bash
npm install
```

2. Gere a versão de build em `dist/`:

```bash
npm run build
```

3. Modo desenvolvimento (watch):

```bash
npm run dev
```
