# landing_page

Landing page responsiva da **Serra Viva Expedições**, criada para o exercício do módulo EBAC.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Plataforma escolhida para deploy

**Vercel**

Passo a passo rápido:

1. Acesse o dashboard da Vercel.
2. Importe o repositório `jadetrubert/landing_page`.
3. Mantenha as configurações padrão de projeto estático.
4. Clique em **Deploy**.
